## Оптимизация топологии в ACELAN

Для реализации методов топологической оптимизации в пакете ACELAN-COMPOS реализован интерфейс `ITopologyOptimisator`.
В нем реализованы два метода оптимизации:
- [ESO](/Developers/OptimizationESO.md)
- BESO

Все вспомогательные функции для оптимизации реализованы в классе `OptHelpers`. 

Основной процесс оптимизации (`TopologyOptimization`) получает модель, данные для ее оптимизации (`topOptConfig`) и данные для решения прямой задачи(`solverConfig`).

`topOptConfig` содержит:
- максимальное количество итераций (`maxN`), 
- процент удаляемого материала (`targetVolume`), 
- количество элементов для удаления за один шаг (`elemForStep`), 
- индекс материала для удаленных элементов (`materialToRemove`)
- наименование функции для оценки чувствительности элемента (`senseName`).

### Ход оптимизации

Полученная на вход сетка кэшируется в словари с учетом материала тела. 
Узлы на которые наложены граничные условия закрепляются, а элементы содержащие эти узлы не подлежат удалению. 
На каждом шаге оптимизации пока не достигнут желаемый объем тела или максимальное количесво шагов:
1. Для каждого элемента оценивается его чувствительность.
2. В случае двунаправленной оптимизации: для элементов с максимальными значениями чувствительности возвращается исходный материал.
3. В элементах с минимальными значениями материал заменяется материалом для удаления.

Для сохранения целостности материала данные о связности сетки хранятся в виде словаря. В качестве ключа выступает номер элемента, в качестве значения- массив номеров связанных с ним элементов. Перед удалением или возвращение для каждого удаляемого элемента проводится проверка: останется ли сетка после изменения материала элемента связной. Для этого соответствующие элементу словаря связности удаляются и определяется компонента связности сетки. Если компонента связности превышает количество удаленных элементов, то материал перестает быть связным и удаление этого элемента отменяется.

Для определения функции оценки чувствительности используется интерфейс `ISensable`.
Элемент может оцениваться через:
- Деформации (`SingleDeformationSense`),
- Напряжения (`SingleStressSense`),
- Осредненные деформации (`AverageDeformationSense`),
- Осредненные напряжения (`AverageStressSense`),
- Перемещения (`SingleMovement`).

При решении задачи оптимизации топологии материала могут задаваться несколько граничных условий. В этом случае задача решается для каждого условия, а чувствительности элемента суммируются.

### Результаты

Результатом оптимизации является JAM файл, содержащий итоговую модель и ее решения.

Также создается файл логов и набор файлов для каждого шага:

- `"DataForTests/optimization_block_{elemRemove}.nas"`
> Файлы в формате .nas для экспорта в COMSOL (`nastranExporter.cs`). 
Создаются на каждом шаге оптимизации и содержат полученную на данном шаге сетку.

- `"DataForTests/optimization_block_{elemRemove}.jam"`
> Создаются на каждом шаге оптимизации (`TopOptSolution.cs`).
Содержат информацию об узлах, элементах, полученных перемещениях, деформациях и напряжениях в каждом элементе.

### Тестирование

Реализованы тесты для моделей из пакета COMSOL. 
Полученные результаты оптимизации хранятся в `acelan\Acelan.Tests\bin\Debug\net7.0\DataForTests`.
Также данные об оптимизации вынесены в проект `acelan_data` в папку `topology_optimization`.
